¿Qué proceso de una empresa conviene automatizar primero? El que se repite cada semana, sigue reglas claras y, si falla, no cuesta un cliente.

Hay tres preguntas para elegirlo:

1. ¿Lo hace alguien del equipo de la misma manera cada vez? Copiar datos de un programa a otro, pasar facturas, contestar las mismas consultas.
2. ¿Se puede escribir en pocas líneas cómo se hace? Si ni el equipo se pone de acuerdo, primero hay que ordenar el proceso y después automatizarlo.
3. ¿Qué pasa si el sistema se equivoca? Para empezar, mejor un proceso con poco riesgo y con una persona que revise.

Lo que se queda en manos de una persona: las reclamaciones delicadas y los cierres de negocio. Se diseña desde el principio quién recibe el caso cuando el sistema no sabe.
