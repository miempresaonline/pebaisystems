¿Hay que cambiar de programa de gestión para usar Inteligencia Artificial? Casi nunca: lo normal es conectarla al que ya usas.

Lo primero es saber qué versión y qué plan tienes, porque la misma marca puede tener conexión oficial en un plan y no en otro. Holded, por ejemplo, tiene API oficial y avisos automáticos. En Odoo, según su documentación, el acceso por API solo está en los planes Custom.

Tres cosas para que salga bien:

1. La IA lee y prepara; una persona confirma. Un pedido mal leído en borrador se corrige en un minuto; uno enviado al cliente, no.
2. La conexión usa una clave solo para eso, con los permisos justos y a nombre de tu empresa, para poder retirarla sin tocar a nadie.
3. Alguien se encarga cuando el programa cambia. Las conexiones se rompen si el programa cambia sus API o sus planes.
