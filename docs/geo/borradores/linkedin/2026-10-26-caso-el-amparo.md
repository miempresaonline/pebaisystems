¿Cómo se lleva la web de una residencia cuando parte del equipo no sabe usar el WordPress? Con un panel hecho para lo que hacen cada día.

La Residencia El Amparo tenía una web muy antigua y un WordPress que no todo el mundo sabía manejar. Les hemos hecho una web nueva y un portal de gestión a su manera.

Desde el portal, el equipo publica subvenciones y noticias, y recibe en un solo sitio las candidaturas de empleo y las solicitudes y visitas de las familias. Ya tiene publicadas 16 subvenciones oficiales, de 2020 a 2026.

Es un trabajo recién entregado, de este mes de octubre. El cliente ha quedado contento y vendrán más trabajos.
