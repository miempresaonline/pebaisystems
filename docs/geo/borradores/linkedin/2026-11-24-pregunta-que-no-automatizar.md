¿Qué no conviene automatizar en una empresa? Lo que exige criterio y trato humano: las reclamaciones delicadas, las negociaciones y los cierres de negocio.

Una forma sencilla de decidirlo:

1. Si el cliente está enfadado o tiene mucho en juego, atiende una persona.
2. Si cada caso es distinto y no hay reglas que se puedan escribir, atiende una persona.
3. Si un error cuesta un cliente, el sistema prepara el trabajo y una persona lo revisa.

Lo que sí se automatiza bien: las consultas repetidas, pasar datos de un programa a otro y los avisos y recordatorios.

Lo importante es diseñar desde el principio quién recibe el caso cuando el sistema no sabe qué hacer. Ese paso decide si el cliente se siente atendido o abandonado.
