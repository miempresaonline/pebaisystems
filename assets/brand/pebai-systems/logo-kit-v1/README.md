# PEBAI Systems — Logo kit v1

El símbolo maestro es la opción 03: una señal direccional verde-violeta con un canal central en forma de S.

Archivos incluidos:

- `pebai-mark-color.svg`: símbolo principal, fondos claros.
- `pebai-mark-ink.svg`: símbolo monocromo para fondos claros.
- `pebai-mark-mineral.svg`: símbolo monocromo para fondos oscuros.
- `pebai-horizontal-dark.svg`: logo horizontal para fondos claros.
- `pebai-horizontal-light.svg`: logo horizontal para fondos oscuros.
- `pebai-stacked-dark.svg`: logo apilado para formatos verticales.
- `favicon.svg`: icono de navegador y aplicaciones.
- `pebai-logo-03-master-transparent-v1.png`: referencia maestra transparente aprobada del símbolo 03; se usa en el hero para preservar exactamente su silueta.

Colores: tinta `#12121A`, mineral `#EFEDE7`, señal `#B7FF3C`, violeta `#6A5CFF`.
