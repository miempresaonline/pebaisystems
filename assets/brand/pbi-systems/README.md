# PBI Systems — identidad visual v1

## Entregables

- `pbi-mark-flow.svg`: variación fluida, más cercana al logo de referencia.
- `pbi-mark-orbit.svg`: variación más compacta y envolvente.
- `pbi-mark-pulse.svg`: variación más angular y energética.
- `pbi-systems-lockups.svg`: lockups claro/oscuro y paleta.
- `pbi-systems-identity-board.svg`: maqueta de identidad con web, móvil y sistema cromático.

## Sistema

- Mineral white: `#EFEDE7`
- Ink: `#12121A`
- Signal green: `#B7FF3C`
- Violet: `#6A5CFF`
- Tipografía de trabajo: Manrope; titulares editoriales en peso 400 y wordmark en peso 700.

Los símbolos son SVG transparentes y escalables. La decisión final debe hacerse entre Flow, Orbit y Pulse antes de preparar exportaciones PNG, favicon y versiones definitivas para producción.
